# FitLogger - Quick Start Guide

## 🚀 Get Started in 5 Minutes

### Step 1: Download (1 minute)
1. Go to: **https://github.com/rana16241-ac/FitLogger-Android-App**
2. Click green **"Code"** button
3. Click **"Download ZIP"**

### Step 2: Extract (30 seconds)
1. Right-click downloaded ZIP
2. Select "Extract All"
3. Choose a location

### Step 3: Open in Android Studio (1 minute)
1. Launch Android Studio
2. Click **"Open"**
3. Select extracted **FitLogger-Android-App** folder
4. Click **"OK"**

### Step 4: Wait for Sync (2 minutes)
- Android Studio will sync Gradle automatically
- Wait for "Gradle sync finished" message
- Don't interrupt this process

### Step 5: Run (1 minute)
1. Click green **Run** button (▶️)
2. Select device/emulator
3. Wait for app to launch

---

## 📱 Quick Test

Once app launches:

1. **Add Activity**: Click + button
2. **Enter**: "Running", "30 minutes", select date
3. **Save**: Click Save button
4. **Verify**: Activity appears on dashboard
5. **Delete**: Click red delete icon
6. **Settings**: Click ⋮ menu → Settings

## 🆘 Quick Troubleshooting

**Problem**: Gradle sync failed  
**Fix**: File → Invalidate Caches → Restart

**Problem**: Build errors  
**Fix**: Build → Clean Project → Rebuild Project

**Problem**: App crashes  
**Fix**: Check device is API 24+ (Android 7.0+)
